# Experiments

One row per training or evaluation run that the team wants to keep. Every run writes its own folder under `runs/` (ignored by git) with `config.json`, `meta.json` (seed, git commit and dirty flag, dependency versions), metrics and the saved model; the "Run folder" column names it. Smoke runs are not logged here.
